# TS3 Streamer No Whisper — релизы

Плагин для TeamSpeak 3: выводит голоса текущего канала на отдельное аудиоустройство (VB-Cable) **без шёпота**. Это устройство добавляется в OBS — зрители стрима слышат канал, а шёпот слышите только вы.

Работает только на сервере `irreale.cleanvoice.ru`.
